Creación Digital · Universidad El Bosque

Misión Representante

Una elección estudiantil convertida en misión: postulación, perfiles de candidatos, votación y publicación de resultados.

  • Next.js 16
  • TypeScript
  • Tailwind CSS 4
  • Firebase
Análisis técnico

Firebase Authentication verifica la identidad institucional; Firestore actualiza fases, candidaturas y votos en tiempo real, y Firebase Storage gestiona los medios. Motion anima las transiciones. Las reglas de Firestore protegen la votación y evitan el voto duplicado.

Hackathon · Seguros Bolívar

Párchate

Una campaña para acercar los seguros a jóvenes con humor, situaciones cotidianas y contenido pensado para compartirse.

  • HTML
  • CSS
  • JavaScript
  • Phosphor Icons
Análisis técnico

El pitch se recorre como una historia vertical por scroll, con piezas gráficas y videos 9:16. Incluye un loader Tetris animado hecho en JavaScript y una interfaz responsive. La campaña incorpora contenido creado con IA.

Hackathon · Global Seguros

Global Seguros

Una propuesta para simplificar el recorrido del cliente y hacer más clara la exploración de coberturas y servicios.

  • HTML
  • CSS
  • JavaScript
  • JSON
Análisis técnico

La landing organiza el journey en pasos, beneficios y preguntas frecuentes, con animaciones de entrada mediante Intersection Observer. El prototipo de catálogo usa datos JSON y el carrito persiste en localStorage; es una simulación frontend, sin servidor, base de datos ni pagos conectados.

Prototipo personal

María Sofía · Portafolio

El primer prototipo para reunir trabajos de 3D, diseño de interfaces y creación digital en un mismo espacio.

  • HTML
  • CSS
  • Google Fonts
Análisis técnico

Maquetación estática con secciones de presentación, servicios, trabajos y blog. La interfaz se apoya en Space Grotesk y estilos CSS; no carga bibliotecas JavaScript. El formulario visible es una demostración frontend, no un envío conectado.

Composición plástica · Relato audiovisual

El Corazón del Asesino

Una narración de suspenso inspirada en Poe, contada con páginas que se abren, imágenes y un pulso sonoro.

  • HTML
  • CSS 3D
  • JavaScript
  • Audio
Análisis técnico

Las páginas giran con transformaciones CSS 3D controladas por inputs checkbox, sin librerías externas. JavaScript sincroniza la música y modifica su velocidad según la escena; el ritmo, el movimiento y el sonido construyen el suspenso.

Portafolio · Experiencia web actual

Marso Studio

Este mismo sitio: una identidad digital que une relato, diseño, código, 3D e ilustración en una experiencia de scroll.

  • HTML
  • CSS
  • JavaScript
  • Canvas + SVG
Análisis técnico

JavaScript dibuja el campo de estrellas en Canvas y coordina las revelaciones con Intersection Observer. Un recorrido SVG responde al scroll; el parallax, la inclinación de tarjetas y el soporte para movimiento reducido completan la interacción.
